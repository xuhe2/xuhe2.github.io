# xuhe2.github.io

Personal homepage built with [Astro](https://astro.build/) and deployed as a static site.

## Development

```sh
nvm use 22
npm install
npm run dev
```

## Build

```sh
nvm use 22
npm run build
```

## Content

Most homepage content lives in `src/data/profile.ts`. Update that file to change the profile text, links, education, experience, research, projects, awards, skills, and footer data.
